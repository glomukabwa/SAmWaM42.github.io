# Leave Application Website

This repository is a collaborative project developed as part of a team effort. The system provides a platform for organization workers to apply for leave. It can be used by different organizations. It separates records of workers depending on the respective organizations that use it.

**My Role and Contributions**  
I contributed primarily to the **backend and database integration**, focusing on:
- Developing the **leave application and approval module** for caretakers and admins.
- Implementing PHP and MySQL functionalities for dynamic data retrieval.
- Participating in UI/UX refinements and testing.

**Technologies Used**
- HTML, CSS, JavaScript  
- PHP (Backend)  
- MySQL (Database)
